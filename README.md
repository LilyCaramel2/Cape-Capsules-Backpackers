# Caramel Digital Design

The official portfolio and service showcase for Caramel Digital Design.

## 🌟 Overview
Built with the "Caramel Aura" design system, this site showcases our web development services, portfolio, and brand identity.

## 🛠️ Tech Stack
- **React 18**
- **Vite**
- **Tailwind CSS** (Custom Caramel Theme)
- **Lucide React** (Icons)

## 📂 Project Structure
- `src/`: Main source code for the portfolio site.
- `cape-capsules/`: Source code for the Cape Capsules Backpackers project (Portfolio Item).
- `halo-glow-site/`: Static site for Halo Glow Beauty (Portfolio Item).

## 🚀 Development
1. `npm install`
2. `npm run dev`

## 📦 Deployment
Deployed to GitHub Pages.
